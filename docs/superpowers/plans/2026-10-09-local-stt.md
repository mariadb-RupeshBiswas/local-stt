# local-stt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `local-stt`, a free, local push-to-talk speech-to-text app for macOS and Windows, installable with `uvx local-stt`.

**Architecture:** One Rust crate (`lib` + `bin`). Pure modules (audio, config, history, models, hotkey matching) are platform-free and unit-tested; platform modules (hotkey hook, paste, hardware probe) sit behind small safe functions. whisper.cpp is compiled in through a tiny C shim. Tauri 2 provides the tray, a non-focusable overlay window and the main window, whose UI is plain HTML/CSS/JS with no bundler. maturin packs the binary into a Python wheel.

**Tech Stack:** Rust 1.99 stable, Tauri 2.12, cpal 0.18, whisper.cpp v1.9.5 (C/C++ via cmake + cc), sha2 0.11, serde, windows-sys 0.61 (Windows), maturin 1.15, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-09-local-stt-design.md`

## Global Constraints

- Crate name `local-stt`, lib name `local_stt`, binary `local-stt`, Tauri identifier `io.github.localstt`.
- Dependencies limited to: `tauri` 2.12 (features `tray-icon`, `macos-private-api`), `tauri-build` 2, `tauri-plugin-clipboard-manager` 2.4, `tauri-plugin-autostart` 2.7, `cpal` 0.18, `serde` 1 (derive), `serde_json` 1, `sha2` 0.11, `windows-sys` 0.61 (Windows only), build-only `cmake` 0.1 and `cc` 1.6. Anything else needs the owner's approval.
- No network access except `curl` to the three pinned Hugging Face model URLs.
- No `unsafe` outside `src/engine.rs`, `src/hotkey/macos.rs`, `src/hotkey/windows.rs`, `src/output/macos.rs`, `src/output/windows.rs`, `src/hwprobe/windows.rs`. Each unsafe call sits in a safe fn and carries a one-line `// SAFETY:` comment. Crate root has `#![deny(unsafe_op_in_unsafe_fn)]`.
- Hotkey code keeps only a "combo held" flag; it never stores, logs or sends any other key.
- Files written by the app (`config.json`, `history.jsonl`, models) are created with mode 0600 on Unix.
- Comments: one line, explain why, not what. No multi-line comment blocks.
- No string `mariadb` anywhere except `mariadb-RupeshBiswas/` URLs and the commit email.
- No em dashes (U+2014) in code, docs, UI text or commits.
- Missing values render as `-`, never `0`.
- Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- UI: no inline `<script>` or `style=""` attributes (CSP `script-src 'self'; style-src 'self'`); set styles through classes or CSSOM (`el.style.x = ...` is allowed).
- Models (exact):

## Review Focus

1. **Hotkey released while transcription still running, then pressed again.** Expect the second press to be ignored with the overlay still showing "Transcribing", never two concurrent transcriptions. Test in Task 8 (`state::tests::press_during_transcribing_is_ignored`).
2. **Corrupt or hand-edited `config.json`** (bad JSON, unknown theme, empty hotkey). Expect defaults for bad fields, the file backed up to `config.json.bak`, app still starts. Test in Task 6 (`config::tests::corrupt_file_falls_back_and_backs_up`, `unknown_fields_ignored`).
3. **Overlay saved on a monitor that is unplugged.** Expect the overlay at bottom-right of the screen with the pointer, never off-screen. Test in Task 8 (`overlay::tests::position_on_missing_monitor_falls_back`).
4. **Model download interrupted or tampered** (network drop, wrong bytes). Expect temp file removed, previous model still active, error shown. Test in Task 6 (`download::tests::checksum_mismatch_deletes_file`).
5. **Silence or a 200 ms tap.** Expect no paste, no history entry for taps under 300 ms, "No speech heard" for silent clips. Tests in Task 3 (`audio::tests::silence_detected`) and Task 8 (`state::tests::short_tap_ignored`).

```c
#include <string.h>
#include "whisper.h"

static void lstt_quiet(enum ggml_log_level level, const char * text, void * user) { (void)level; (void)text; (void)user; }

void * lstt_load(const char * path) {
    whisper_log_set(lstt_quiet, NULL);
    struct whisper_context_params cp = whisper_context_default_params();
    return whisper_init_from_file_with_params(path, cp);
}

int lstt_transcribe(void * ctx, const float * pcm, int n, int translate, const char * lang, int threads, char * out, int out_len) {
    if (!ctx || !out || out_len <= 0) return -1;
    out[0] = '\0';
    if (n <= 0) return 0;
    struct whisper_full_params p = whisper_full_default_params(WHISPER_SAMPLING_GREEDY);
    p.translate = translate != 0;
    p.language = (lang && lang[0]) ? lang : "auto";
    p.detect_language = false;
    p.n_threads = threads > 0 ? threads : 4;
    p.print_progress = false; p.print_realtime = false; p.print_timestamps = false; p.print_special = false;
    p.no_timestamps = true; p.single_segment = false; p.suppress_blank = true;
    if (whisper_full((struct whisper_context *)ctx, p, pcm, n) != 0) return -2;
    int segs = whisper_full_n_segments((struct whisper_context *)ctx);
    size_t used = 0;
    for (int i = 0; i < segs; i++) {
        const char * t = whisper_full_get_segment_text((struct whisper_context *)ctx, i);
        size_t len = strlen(t);
        if (used + len + 1 > (size_t)out_len) return -3;
        memcpy(out + used, t, len);
        used += len;
    }
    out[used] = '\0';
    return 0;
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;
    fn mon(name: &str, x: f64, y: f64, w: f64, h: f64) -> Screen { Screen { name: name.into(), x, y, w, h } }
    #[test]
    fn default_is_bottom_right_of_pointer_screen() {
        let screens = [mon("A", 0.0, 0.0, 1440.0, 900.0), mon("B", 1440.0, 0.0, 1920.0, 1080.0)];
        assert_eq!(default_pos(&screens, (2000.0, 500.0), (220.0, 44.0)), (1440.0 + 1920.0 - 24.0 - 220.0, 1080.0 - 24.0 - 44.0));
    }
    #[test]
    fn position_on_missing_monitor_falls_back() {
        let screens = [mon("A", 0.0, 0.0, 1440.0, 900.0)];
        let saved = OverlayPos { monitor: "Gone".into(), x: 3000.0, y: 100.0 };
        assert_eq!(resolve(&screens, Some(&saved), (10.0, 10.0), (220.0, 44.0)), (1440.0 - 244.0, 900.0 - 68.0));
    }
    #[test]
    fn snaps_near_corner() {
        let s = mon("A", 0.0, 0.0, 1440.0, 900.0);
        assert_eq!(snap(&s, (1440.0 - 220.0 - 10.0, 900.0 - 44.0 - 5.0), (220.0, 44.0)), (1440.0 - 244.0, 900.0 - 68.0));
    }
    #[test]
    fn free_position_kept_away_from_edges() {
        let s = mon("A", 0.0, 0.0, 1440.0, 900.0);
        assert_eq!(snap(&s, (600.0, 400.0), (220.0, 44.0)), (600.0, 400.0));
    }
    #[test]
    fn clamped_inside_work_area() {
        let s = mon("A", 0.0, 25.0, 1440.0, 875.0);
        assert_eq!(snap(&s, (-50.0, 0.0), (220.0, 44.0)), (24.0, 49.0));
    }
}
```
